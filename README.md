# YouTube Focus

유튜브의 추천 영역을 가려 검색한 영상만 보게 해주는 크롬 확장입니다.

## 기능

- **홈 피드 숨김**: 영상 격자, 필터 칩, Shorts 선반을 가리고 안내 문구만 표시
- **영상 페이지 추천 숨김**: 오른쪽 추천 목록, 하단 추천, 종료 화면 추천
- **댓글 숨김**: 영상 댓글 영역과 쇼츠 댓글 버튼
- **검색·구독 피드는 그대로**

## 설치

1. 이 저장소를 클론하거나 ZIP으로 다운로드
2. 크롬에서 `chrome://extensions` 접속
3. 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** 클릭 후 프로젝트 폴더 선택
5. 열려 있던 유튜브 탭 새로고침

## 업데이트

압축해제된 확장은 자동으로 갱신되지 않습니다.

1. 로드한 폴더에서 `git pull`
2. `chrome://extensions`에서 확장 카드의 새로고침 아이콘 클릭
3. 열려 있던 유튜브 탭 새로고침
