# YouTube Focus

유튜브 홈 피드와 추천 영상을 가리는 크롬 확장입니다. 검색은 손대지 않습니다.

| 화면 | 동작 |
| --- | --- |
| 홈 (`youtube.com/`) | 영상 격자, 필터 칩, Shorts 선반을 모두 숨기고 안내 한 줄만 남김 |
| 검색 (`/results`) | 그대로. 어떤 규칙도 검색 결과를 겨냥하지 않음 |
| 영상 (`/watch`) | 오른쪽 추천 목록, 하단 추천, 종료 화면 추천 숨김 |
| 영상 · 쇼츠 댓글 | 댓글 영역과 쇼츠 댓글 버튼 숨김 (팝업에서 따로 끌 수 있음) |
| 구독 피드 (`/feed/subscriptions`) | 그대로 |

재생목록 대기열과 실시간 채팅은 남겨뒀습니다. 오른쪽 열 전체가 아니라 추천 영역만
골라 숨기기 때문입니다.

## 설치

1. 크롬 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭 후 이 폴더 선택
4. 유튜브 탭이 열려 있었다면 한 번 새로고침

엣지, 웨일, 브레이브 등 크로미움 계열 브라우저도 같은 방식으로 됩니다.
파이어폭스는 `manifest.json`의 `background`/`action` 규격이 조금 달라 별도 수정이 필요합니다.

## 구조

```
manifest.json   확장 정의
content.css     실제로 숨기는 규칙 전부
content.js      설정값을 <html> 속성으로 옮기고 페이지 종류를 표시
popup.html/js   툴바 아이콘을 눌렀을 때 뜨는 켬/끔 패널
```

숨김은 전부 CSS가 담당합니다. 자바스크립트로 DOM을 지우지 않기 때문에 유튜브가
화면을 다시 그려도 깜빡이거나 되살아나지 않습니다.

## 규칙 추가하기

더 가리고 싶은 요소가 있으면 유튜브에서 F12 → 요소 선택 → 태그 이름을 확인한 뒤
`content.css`의 해당 섹션에 한 줄 추가하면 됩니다. 예를 들어 홈의 사이드바까지
접어두고 싶다면:

```css
html[data-ytf-home="on"][data-ytf-page="home"] #guide,
html[data-ytf-home="on"][data-ytf-page="home"] ytd-mini-guide-renderer {
  display: none !important;
}
```

## 알아둘 점

유튜브는 내부 태그 이름을 종종 바꿉니다. 언젠가 일부 항목이 다시 보이기 시작하면
위 방법으로 선택자만 갱신하면 됩니다. 크롬 웹스토어에 올리려면 128px 아이콘과
개인정보 처리방침이 추가로 필요합니다.
